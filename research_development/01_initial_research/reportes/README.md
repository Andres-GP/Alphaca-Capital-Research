# Reportes de investigación

Guardar cada entrega en `YYYY-MM-DD_<familia>/`. Incluir árbol de familia → pauta → mercado → hipótesis → veredicto y documentos revisables Markdown/YAML; el PDF solo se genera cuando haya una investigación con resultados que reportar. No crear resultados de relleno para familias aún no investigadas. Aplicar los criterios de [`../GATES.md`](../GATES.md) y tokens visuales de [`../README.md`](../README.md).
